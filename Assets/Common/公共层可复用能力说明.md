# 公共层可复用能力说明

本文档是给 AI 和开发者的公共层能力索引。只记录“有什么、优先复用什么”，具体字段和调用细节按需查看 `Assets/Common/Scripts` 源码。

公共层运行时命名空间：`HuanYouYu.MiniGameHall`。

## 使用原则

- 新增或改造子游戏前，先检查本文档和 `Assets/Common`，已有公共能力优先复用。
- 不要在子游戏里重复实现公共壳、弹窗、结算、文案、音效、关卡进度、基础 UI 构件。
- 子游戏不要直接修改大厅存档或累计金币/宝箱，奖励入账统一走公共结算/大厅流程。
- 子游戏 UI 文案优先走 `UiTextCatalog`，共享语义已存在时复用共享 key，不在子游戏文案里重复定义。
- 连连看保留的新手引导走 `MiniGameBase.TryStartTutorial(...)` 和 `MiniGameTutorialOverlay`，其它玩法不要再新增引导入口。

## 小游戏壳与流程

- `MiniGameBase`：子游戏运行体基类，提供统一壳、宿主协程、暂停、结算、返回大厅、奖励发放入口。
- `MiniGameBase.TryStartTutorial(...)` / `CloseTutorial()`：连连看新手引导入口，按版本判断是否展示，并在完成后写入引导记录。
- `MiniGameShell`：统一小游戏壳，提供顶部/内容/底部挂载点，以及暂停、提示、退出确认、结算等公共弹窗。
- `MiniGameShellLayout`：调整统一壳顶部和底部预留空间。

## 公共结算与进度

- `MiniGameSettlement`：子游戏向大厅提交的结算数据。
- `MiniGameBase.ShowSettlementAndComplete(...)`：普通“弹出结算后返回大厅”流程。
- `MiniGameBase.ShowRewardSettlementPanel(...)`：奖励结算面板底层流程，支持成功、失败、中性样式和下一关/重试/继续/确认/返回大厅等主按钮语义。
- `MiniGameBase.ShowBackHallRewardSettlementPanel(...)`：主动返回大厅时优先使用的奖励结算流程；主按钮固定为“返回大厅”，不显示“再来一局”。
- `MiniGameBase.GrantSettlementReward(...)`：本局不结束但奖励要先入账时使用，例如通关后继续下一关。
- `MiniGameLevelProgressController`：线性关卡选择、解锁、下一关控制。
- `MiniGameProgressData`：大厅保存的单个子游戏进度数据。
- `IMiniGameTutorialStore`：大厅侧提供的子游戏引导版本读写接口，目前用于连连看引导。

## 通用 UI

- `MiniGameShellTopBarBuilder`：统一风格顶部信息栏，适合标题、分数、关卡、状态等；支持额外状态文本和局部自定义文本样式。
- `MiniGameShellBottomBarBuilder`：统一风格底部操作区和常用按钮。
- `MiniGameDirectionPadBuilder`：方向键 UI。
- `MiniGameDropdown`：公共下拉选项控件，适合子游戏顶部或设置区的少量选项切换。
- `MiniGameLevelSelectView`：公共选关弹窗。
- `MiniGameTutorialOverlay` / `MiniGameTutorialStep`：连连看新手引导覆盖层，支持目标高亮、说明气泡、跳过/下一步，以及需要点击目标才能推进的手把手步骤。
- `MiniGameWinSettlementView`：公共奖励结算面板；子游戏通常通过 `MiniGameBase.ShowRewardSettlementPanel(...)` 或 `MiniGameBase.ShowBackHallRewardSettlementPanel(...)` 使用。

## 文案、音频与设置

- `UiTextCatalog`：读取共享文案和子游戏文案，优先使用 `Get` / `Format`。
- `MiniGameFontProvider`：统一小游戏 TMP 字体来源；子游戏动态创建文本时优先使用 `DefaultFont`。
- `MiniGameSfxPlayer`：统一音效播放和按钮音效绑定。
- `MiniGameRuntimeSettings`：音乐、音效、震动开关状态；公共暂停面板已绑定。
- `MiniGamePauseToggleView`：公共暂停面板内部的设置开关视图，承载音乐、音效、震动开关状态与动画。

## 资源与绘制工具

- `MiniGameIconCatalog`：读取公共图标贴图。
- `MiniGameSafeAreaUtility`：安全区辅助工具，供公共壳或子游戏布局计算顶部避让。
- `RoundedRectGraphic`：运行时圆角矩形图形组件。
- `DirectionTriangleGraphic`：运行时方向三角图形组件。
- `PopupPanelTopDecorUtility`：弹窗顶部装饰工具。
- `UiTweenRunner`：承载轻量 UI 动画协程。
