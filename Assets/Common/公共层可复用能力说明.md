# 公共层可调用功能说明

本文档只说明当前主工程 `Assets/Common` 里可供子游戏直接调用的公共功能。

公共层运行时命名空间：`HuanYouYu.MiniGameHall`。

## 小游戏入口与统一壳

### `MiniGameBase`

所有子游戏运行体继承该类后，可直接获得统一小游戏壳、宿主协程能力、结算回调和返回大厅回调。

可用成员：

- `GameId`：当前游戏 id。
- `HostBehaviour`：宿主 `MonoBehaviour`，用于 `StartCoroutine` / `StopCoroutine`。
- `CompleteGame`：结算完成后通知大厅。
- `ExitToHall`：直接返回大厅。
- `Shell`：统一小游戏壳，提供 UI 挂载点和弹窗能力。
- `Tick(float deltaTime)`：需要逐帧逻辑时重写。
- `ShowSettlementAndComplete(MiniGameSettlement settlement)`：弹出结算并在确认后回大厅。
- `OnBeforeDispose()`：释放事件、协程、临时对象时重写。

### `MiniGameShell`

统一小游戏壳，包含背景、暂停按钮、顶部区域、内容区域、底部区域和弹窗层。

可用能力：

- `SetPauseButtonVisible(bool visible)`：显示或隐藏暂停按钮。
- `SetBackgroundVisible(bool visible)`：显示或隐藏统一背景。
- `AttachTop(Transform target)`：挂载顶部 UI。
- `AttachContent(Transform target)`：挂载主体玩法 UI。
- `AttachBottom(Transform target)`：挂载底部操作 UI。
- `ClosePopup()`：关闭当前弹窗。
- `ShowPausePopup(Action onResume, Action onConfirmExit)`：显示公共暂停面板，内含继续、退出、玩法说明、音乐、音效、震动开关。
- `ShowInfoPopup(string message, Action onConfirm = null)`：显示普通提示弹窗。
- `ShowExitConfirmPopup(Action onCancel, Action onConfirm)`：显示返回大厅确认弹窗。
- `ShowSettlementPopup(string message, Action onConfirm, string confirmLabel = null)`：显示单按钮结算弹窗。
- `ShowSettlementChoicePopup(...)`：显示双按钮结算弹窗。
- `ShowRetryOrExitPopup(...)`：显示重试或返回大厅弹窗。

### `MiniGameShellLayout`

调整统一壳的顶部和底部预留空间。

- `MiniGameShellLayout.Default`：默认顶部、内容、底部布局。
- `MiniGameShellBottomMode.DefaultSlot`：使用公共底部槽。
- `MiniGameShellBottomMode.OwnedByContent`：底部空间由玩法内容自行管理。

## 通用 UI 构建

### `MiniGameShellTopBarBuilder`

创建统一风格顶部信息栏。

适合展示：

- 游戏标题
- 分数
- 关卡
- 回合
- 剩余步数
- 当前状态

常用方法：

- `CreateDefaultConfig(string instanceName)`
- `CreateReversiConfig(string instanceName)`
- `CreateTextStyle(...)`
- `CreateTopBar(Transform parent, TopBarConfig config)`

返回的 `TopBarRefs` 包含：

- `Root`
- `TitleText`
- `ScoreText`
- `ExtraText`

### `MiniGameShellBottomBarBuilder`

创建统一风格底部操作区和常用按钮。

常用方法：

- `CreateBottomContainer(...)`
- `CreateRestartButton(...)`
- `CreateShuffleButton(...)`
- `CreateHintButton(...)`
- `CreateLevelSelectButton(...)`

返回的 `ButtonRefs` 包含：

- `Button`
- `Root`
- `Icon`

按钮创建后仍需子游戏自行绑定点击事件。点击音效优先用 `MiniGameSfxPlayer.Attach`。

### `MiniGameDirectionPadBuilder`

创建方向键 UI，适合方向移动、格子移动、蛇类玩法。

返回的 `References` 包含：

- `Root`
- `UpButton`
- `DownButton`
- `LeftButton`
- `RightButton`

### `MiniGameLevelSelectView`

创建公共选关弹窗，适合有关卡列表和线性解锁的玩法。

可传入：

- 总关卡数
- 当前关卡索引
- 已解锁关卡数
- 选择关卡回调
- 关闭回调

### `MiniGameWinSettlementView`

创建公共胜利结算面板，适合需要展示奖励、关卡信息和下一关按钮的玩法。

相关数据类型：

- `MiniGameRewardSettlementPanelParams`
- `MiniGameSettlementInfoRow`

## 文案

### `UiTextCatalog`

统一读取共享文案和子游戏文案。

常用方法：

- `Get(string key)`：读取文案，缺失时返回 `?`。
- `Format(string key, params object[] args)`：读取并格式化文案。

使用要求：

- 新增子游戏文案优先使用 `Get` 或 `Format`，并确保对应 key 已写入文案 json。
- 尽量不要使用 `GetOrFallback`；它只适合兼容旧代码或临时兜底，不能替代补全文案配置。

公共文案文件：

- `Assets/Common/Resources/Text/ui_texts.shared.zh-CN.json`

公共暂停面板会使用 `MiniGameBase.GetPauseHelpKeys()` 返回的 key 读取玩法说明和制作名单。

## 音频与运行时设置

### `MiniGameSfxPlayer`

统一音效播放和按钮音效绑定。

常用方法：

- `Attach(Button button, MiniGameSfxType type = MiniGameSfxType.UiTap, float volumeScale = 1f)`
- `Play(MiniGameSfxType type, float volumeScale = 1f, float pitch = 1f)`
- `Play(AudioClip clip, float volumeScale = 1f, float pitch = 1f)`

可用音效类型：

- `UiTap`
- `UiBack`
- `TileSelect`
- `MatchSuccess`
- `MatchFail`
- `Settle`

### `MiniGameRuntimeSettings`

统一运行时设置。

可读状态：

- `MusicEnabled`
- `SfxEnabled`
- `VibrationEnabled`

可用方法：

- `SetMusicEnabled(bool enabled)`
- `SetSfxEnabled(bool enabled)`
- `SetVibrationEnabled(bool enabled)`

可订阅事件：

- `Changed`

公共暂停面板已经绑定这些设置，子游戏一般只需要读取状态或在特殊玩法里响应 `Changed`。

## 结算与进度数据

### `MiniGameSettlement`

子游戏结束时传给大厅的结算数据。

字段：

- `Score`
- `ChestCount`
- `CoinCount`
- `Summary`

### `MiniGameProgressData`

大厅保存的单个子游戏进度数据。

字段：

- `GameId`
- `PlayCount`
- `BestScore`
- `TotalChestCount`
- `TotalCoinCount`
- `CurrentLevelIndex`
- `UnlockedLevelCount`

### `MiniGameLevelProgressController`

线性关卡解锁控制器。

可用属性：

- `CurrentLevelIndex`
- `UnlockedLevelCount`
- `LevelCount`

可用方法：

- `CanSelect(int index)`
- `Select(int index)`
- `UnlockNext()`
- `CanGoNext()`
- `GoNext()`

## 图标与资源

### `MiniGameIconCatalog`

统一读取公共图标贴图。

常用属性和方法：

- `ClassicLinkIconCount`
- `Match3IconCount`
- `GetClassicLinkTexture(int value)`
- `GetMatch3Texture(int value)`
- `GetTexture(string key)`
- `GetClassicLinkDisplayName(int value)`

公共资源路径：

- `Assets/Common/Resources/GameIcons`
- `Assets/Common/Resources/HallTheme`
- `Assets/Common/Resources/MiniGameShell.prefab`
- `Assets/Common/Resources/MiniGamePopup.prefab`
- `Assets/Common/Resources/MiniGamePausePopup.prefab`

## 通用绘制与小工具

### `RoundedRectGraphic`

运行时圆角矩形图形组件，适合按钮底、面板底、遮罩底。

可用属性：

- `CornerRadius`

### `DirectionTriangleGraphic`

运行时方向三角图形组件，适合方向键箭头。

### `PopupPanelTopDecorUtility`

弹窗顶部装饰工具。

可用方法：

- `CreateMirroredTopDecor(Transform parent, Sprite sprite, float panelWidth)`

### `UiTweenRunner`

轻量 `MonoBehaviour`，用于承载 UI 动画协程。

## 优先复用速查

- 暂停、设置、玩法说明：`Shell.ShowPausePopup`
- 提示弹窗：`Shell.ShowInfoPopup`
- 退出确认：`Shell.ShowExitConfirmPopup`
- 结算弹窗：`Shell.ShowSettlementPopup` / `MiniGameWinSettlementView`
- 顶部状态栏：`MiniGameShellTopBarBuilder`
- 底部操作栏：`MiniGameShellBottomBarBuilder`
- 方向键：`MiniGameDirectionPadBuilder`
- 选关弹窗：`MiniGameLevelSelectView`
- 关卡解锁：`MiniGameLevelProgressController`
- 文案读取：`UiTextCatalog`
- 点击音效和玩法音效：`MiniGameSfxPlayer`
- 音乐、音效、震动开关：`MiniGameRuntimeSettings`
- 公共图标：`MiniGameIconCatalog`
- 圆角 UI：`RoundedRectGraphic`
- 方向箭头：`DirectionTriangleGraphic`
