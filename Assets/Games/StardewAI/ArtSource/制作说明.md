# 梦幻森居美术重制

本次范围：替换 AI 星露谷全部原有位图美术，包括角色、NPC、地面、作物、建筑、植被、工具、图标和反馈效果。玩法和碰撞地图保持兼容。

## 角色与换装

角色使用统一体型、正面／侧面／背面分件。左侧朝向由右侧镜像。发型、上衣（含袖子）、下装（含裤腿）、鞋、围巾、帽子分别更换，共用骨骼。首版各槽两种选择；帽子为无帽／草帽。选择保存在本机。

骨架包含髋、躯干、头、双肩、双肘、双手、双膝、双踝。侧面步态用 Unity 现有 2D IK 求解，前后方向按纵深投影处理。新体型或长裙／披风需要单独适配，不能当普通短装直接替换。

## 2026-09-08 单角色步行动作样片

本轮只验证现有主角的步行，不扩展地图或新服装。此前的素材制作记录不代表美术质量已获认可。

已确认的动作问题：移动速度 4.25、完整步行周期距离 1，导致每秒 8.5 步；同侧手脚同步向前；脚踝始终水平；重心几乎不随承重阶段变化。

参考 Animator Island 的四阶段步行讲解：https://www.animatorisland.com/secret-of-animation-walks-simplified/ ，以及 SideFX 的 Character Walk Cycle Workshop：https://www.sidefx.com/tutorials/character-walk-cycle-workshop/ 。本次参考动作设计原则，没有导入他人的角色或动画文件。

现用原生 2D IK 配合落脚、承重、经过、抬起的重心曲线，支撑期占周期 60%，加入脚跟与脚尖滚动、反向摆臂。完整周期距离 0.84，移动速度同步降为 0.9，约每秒 2.14 步。游戏内移动也随之变慢，这是当前步行样片的取舍；后续若需要快速移动，需要单独设计快走或跑步，不能只加快短步幅循环。

执行相关 StardewAI PlayMode 测试，9/9 通过，包括双向移动、平脚支撑期接地、换装与工具兼容、单角色录制。测试不能判断动作是否好看。已检查关键姿势，短裤、袖口等分件仍有明显硬边，此版仅作为动作评审样片。

录制方式：设置 STARDEW_WALK_CAPTURE_DIR 后运行 ci/run_playmode_tests.ps1 -TestFilter StardewAI。单角色序列位于输出目录的 single 子目录；固定服装、素色背景，依次待机、右走、停步、左走、停步。

## B 样片重做：网格蒙皮与整体关键姿势（2026-09-08）

上一节的刚性分件样片被用户明确否定，本轮保留 B 的图像素材，重新制作蒙皮及动作。没有替换正式游戏主角。

上衣、袖子、前臂、裤腿、小腿、头发和领巾改为 Unity 原生 SkinnedMeshRenderer，每个部件使用 4×12 网格和两根骨骼之间的渐变权重。使用现有引擎能力，没有新增软件或依赖。头部、腰带和鞋保留刚性层；不把这称为 SpriteSkin 实现。

腰与胸部有了分开的骨骼。动作以八个整体关键姿势安排髋部高度、重心偏移、骨盆转动、胸部倾斜、头部补偿和手臂动作；相邻姿势以周期连续的切线连接。头发和领巾带轻微延后运动。完整行走周期为 1 秒，周期位移 20/64 世界单位。远侧肩膀向身体内收，避免斜侧面动作读成两臂同时外张。

验证新增了实际 BakeMesh 变形检查：裤腿相对单根骨骼必须产生弯曲、变形幅度不能异常放大、回到中立姿势后顶点应恢复原形。检查时发现该骨架的 BakeMesh 结果包含 1/64 根骨缩放，已先统一坐标再比较。原有接地、骨长、短腿弯曲与原主角兼容检查保留。

录制使用 ci/run_playmode_tests.ps1 -TestFilter StardewAISideWalkTests，STARDEW_WALK_CAPTURE_DIR 指向 TestResults/b-skinned/final。新旧对照中左侧为之前的刚性分件版本，右侧为本轮蒙皮版本。旧样片的记录与预览保留，测试通过不代表审美已获认可。
